## ターミナルと Source Control の比較（E-3）

- ターミナルでは `git status` や `git diff` を毎回打って確認する必要があったが、Source Control では変更されたファイルと差分が常に表示されていて、確認の手間が少なかった
- `git add` でファイル名を打つ代わりに `+` ボタンを押すだけでよく、打ち間違いが起きない
- 一方で、`add` → `commit` → `push` の順番と意味は、ターミナルで 1 つずつ実行したことで理解できた
